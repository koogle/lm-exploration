Adapted from the user-requested Age of Agents documentation workflow (2026-10-11).

1. Consult AGENTS.md, README.md, decisions.md, OPEN_WORK.md and the knowledge index.
   Read guides relevant to the next action; check important claims against source.
2. Work within the authorized research scope. Keep hypotheses separate from facts.
3. Capture durable corrections, methods, troubleshooting, limitations and measured
   outcomes at meaningful checkpoints. Link papers and pinned code references.
4. Update owning documents in place and keep the knowledge index short. Current
   blockers belong in OPEN_WORK.md; measurements belong in results/ with provenance.
5. Before handoff, commit or push, reconcile docs with the code and checks actually
   executed. Check links, `git diff --check`, and project validation. Do not erase
   unresolved work or claim unexecuted experiments succeeded.
