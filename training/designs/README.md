# Training interface designs

Imported unchanged from [web-inference PR #1](https://github.com/koogle/web-inference/pull/1),
commit `3906ff5ae5cceb1ce7064ede8550f6820fa681fe`.

- [Run Board web](run-board-web.html): latest direction; Modal-hosted web UI,
  baseline selection, equal-token loss differences, and an A-vs-B panel showing
  code, configuration, data and samples.
- [Training studies](train-design-studies.html): earlier Run Board, Compare and
  Pipeline layouts. The Run Board was revised to expose exact model code and
  the data mixture for each run.

These are standalone interactive mockups with made-up runs and metrics. Their
buttons do not launch real training jobs. The companion iPad designs are in
[phone inference](../../inference/phone/designs/ipad-design-studies.html).
